# Pilote JDBC MySQL

Le projet utilise **MySQL Connector/J 9.6.0** (coordonnees Maven :
`com.mysql:mysql-connector-j:9.6.0`). Telecharger cette version depuis la
distribution officielle MySQL et placer le fichier dans ce dossier :

```text
lib/mysql-connector-j-9.6.0.jar
```

SHA-256 du fichier utilise pour la verification locale :

```text
66df1d453789dc8cb759a7dc17f58646893bf28483f262328650f170472a6ead
```

Le binaire installe est ignore par Git. Conserver ce document pour connaitre
la version requise lors d'un nouveau clonage.
